🏎️ GARAGE INFO

Manage your services and images

⚙️ Supabase Configuration Required

To enable this feature, configure RLS policies in Supabase:

  1. Enable RLS on tables: garage_services and garage_images
  2. Create Policy for Services (Allow SELECT, INSERT, DELETE for anon users)
    CREATE POLICY "Allow public access" ON garage_services FOR ALL USING (true) WITH CHECK (true);
  3. Create Policy for Images (Same as above)
    CREATE POLICY "Allow public access" ON garage_images FOR ALL USING (true) WITH CHECK (true);
  4. Configure Storage Bucket: Make garage-images bucket public
  5. Refresh this page after configuration
